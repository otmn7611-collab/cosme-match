# コスメ相性ノート

口コミの評価から、化粧品の人気ランキングと「肌質・組み合わせの相性」を見られるサイトです。
GitHub Pages でそのまま公開できます。

## 機能
- **ランキング**：楽天市場のレビュー平均・件数から算出した人気順（カテゴリ別）
- **肌質別**：乾燥肌・脂性肌・混合肌・敏感肌・普通肌ごとの評価ランキング
- **併用チェック**：2つのアイテムを一緒に使った人の評価＋成分の組み合わせメモ
- **口コミ投稿**：肌質・評価・併用アイテムを投稿

## ファイル構成
| ファイル | 役割 |
|---|---|
| index.html | 画面 |
| style.css | デザイン |
| app.js | 集計・表示・楽天API取得 |
| data.js | カテゴリ・肌質・成分ルール・サンプルデータ |
| config.js | 楽天APIのキー設定 |

## 公開手順（GitHub Pages）
1. GitHubで新しいリポジトリを作り、このフォルダのファイルをすべてアップロード
2. Settings → Pages → Branch を `main` / `/(root)` にして保存
3. 表示されたURL（例：`https://ユーザー名.github.io/cosme-match/`）を開く

キー未設定の間は、**架空ブランドのサンプルデータ**で表示されます。

## 楽天の実データに切り替える
1. [楽天ウェブサービス](https://webservice.rakuten.co.jp/) に楽天IDでログインし、アプリを新規登録
2. アプリ設定の「**WebサイトURL（許可するドメイン）**」に GitHub Pages のURLを登録
   （登録していないと403エラーになります）
3. 発行された「アプリケーションID」と「アクセスキー（pk_〜）」を `config.js` に入力
4. `config.js` をGitHubに再アップロード

取得したデータはブラウザに6時間キャッシュされます（`CACHE_HOURS` で変更可）。

## 注意事項・今後の課題
- **口コミ投稿は今はその端末のブラウザにのみ保存されます。** 利用者全員の投稿を集計するには、
  Supabase や Firebase などのデータベースを追加する必要があります。
- 成分メモは「商品名」から推定しています。実際の配合とは異なる場合があります。
- 楽天のレビュー**本文**は取得・表示していません（数値のみ）。
- 「効く」「治る」など効果効能を断定する表現は、薬機法・景品表示法に触れるおそれがあるため避けてください。
- 楽天APIを使うページには「Supported by Rakuten Developers」のクレジット表示が必要です（フッターに設置済み）。
